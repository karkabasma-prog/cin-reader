# CIN Reader — Frontend

Interface web du projet **CIN Reader**, permettant de déposer la photo du recto d'une CIN marocaine et d'afficher les informations extraites par le backend.

Pour la présentation complète du projet (contexte, architecture, backend, IA), voir le [README principal](../README.md).

## Stack technique

- React 19 + TypeScript
- Vite (build et serveur de développement)

## Commandes disponibles

```bash
npm install       # installer les dépendances
npm run dev       # lancer le serveur de développement (http://localhost:5173)
npm run build     # construire la version de production
npm run preview   # prévisualiser la version construite
npm run lint      # vérifier le code avec ESLint
```
